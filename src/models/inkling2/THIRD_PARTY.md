# Third-party material

The code in this directory was imported from `headbouyJB/inkling2-gufo` at
`8bb6cd5` (MIT, see `LICENSE.inkling2`) and has been changed in Gufo since.
Paths below are relative to `src/models/inkling2/`. No third-party source file
is vendored; images are decoded by Gufo's own image decoder.

Code copied or adapted from other projects:

- `kFp4` and `kIq4nl` (lookup tables in `hip/kernels.hip`): copied data from
  ggml's `kvalues_fp4` and `kvalues_iq4nl` tables (`ggml-common.h`, llama.cpp
  `e412c6f`). The same e2m1 values also appear as packed byte constants in
  `hip/fast.hip`.
- `scale_min_k4` in `hip/kernels.hip` mirrors ggml's `get_scale_min_k4`
  (`ggml-quants.c`, `e412c6f`).

The llama.cpp MIT licence text is reproduced below, as MIT requires for
copied portions.

Facts about the formats and algorithms were taken from, and checked against,
these projects. They are cited, not copied.

## hip/kernels.hip, engine.cpp (forward pass)
- Dequantisation of NVFP4, Q8_0, Q5_0, Q4_K, Q5_K, Q6_K, IQ4_NL and IQ4_XS blocks, the `kvalues_fp4` / `kvalues_iq4nl` tables, `ggml_ue4m3_to_fp32` and `get_scale_min_k4` are re-implemented as HIP device functions from `ggml/src/ggml-quants.c`, `ggml-common.h` and `ggml-impl.h` (llama.cpp e412c6f, MIT). The `kvalues_fp4` / `kvalues_iq4nl` tables are copied data and `scale_min_k4` mirrors `get_scale_min_k4` (see above); the rest is written out in our own structure (item-wise dequantisation into registers).
- The forward pass (block attention residual `mix`, `control`, `convolve`, `clip`, relative-bias attention with sink, SITU MoE, loop schedule and slot layout) follows `src/models/inkling2.cpp` and `src/models/inkling2-loop.cpp` (llama.cpp e412c6f + 29b52d3, MIT) as described in `docs/internal/models/inkling-2-mini/FORWARD.md`; no source was copied.
- `tests/oracle/llama_dump.cpp` links libllama (llama.cpp e412c6f + the PR #32704 cherry-pick, MIT) as the numerical oracle.

## vision/ (vision encoder)
- Algorithm (patch layout, 2-D RoPE, position-table resize, merge permute, preprocessing and size limits) re-implemented from llama.cpp e412c6f (MIT): `tools/mtmd/models/inkling2v.cpp`, `tools/mtmd/mtmd-graph.cpp` (`build_vit`, `build_inp`, `resize_position_embeddings`, `build_rope_2d`, `build_patch_merge_permute`), `tools/mtmd/mtmd-image.cpp` (`mtmd_image_preprocessor_inkling2v`, `calc_size_preserved_ratio`), `ggml/src/ggml-cpu/ops.cpp` (bilinear `upscale_f32`). No code copied verbatim.

## Other files and data

- `text/*` (tokenizer, pre-tokenizer, chat-template renderer, JSON values,
  tool dialect): original code. It reproduces the behaviour of the official
  Inkling 2 Mini `tokenizer.json` and `chat_template.jinja` (Apache 2.0, from
  the model repository); the tests compare against the output of those
  files. The split regex in `pretokenizer.hpp` is the one in the official
  `tokenizer.json`.
- `text/unicode_tables.cpp`: generated by `text/tools/gen_unicode_tables.py`
  from Python's `unicodedata` (Unicode 16.0.0); Unicode data is under the
  Unicode License v3.
- `tests/text/goldens/*.json`: expected tokenisations and renderings produced
  by `tests/text/tools/gen_goldens.py` with the official tokenizer, tiktoken
  and jinja2. Some cases contain excerpts of the WikiText-2 test split
  (Wikipedia text, CC BY-SA 3.0).
- `hip/fast.hip`: original code from the extension's kernel lab, with the
  prefill GEMMs, fused MoE tail and decode launch changes made in Gufo.
- `tests/`: original test programs; `tests/oracle/llama_dump.cpp` links
  libllama of a llama.cpp build as the oracle and contains no llama.cpp
  source.
- No code was taken from AGPL-licensed projects.
