# PR #543 cache issue audit

GitHub issue bodies and states were read on October 11, 2026. Searching both open and closed issues for `cache in:title,body` returns 106 issues. Expanding the search to checkpoint, prefill and continuation gives 160 unique issues (139 closed, 21 open). The complete inventory is below; a closed issue is not assumed to remain fixed.

This migration changes Flash-Next AR/MTP serving. Qwen 27B and DeepSeek retain their legacy caches. “Covered” means the listed behavior has direct test evidence, not that every requirement or historical client reproduction is resolved. Partial, unresolved, unsupported and unverified cases remain explicit.

Evidence is retained under `/home/mixer/gufo-qualification/pr543-review-2026-10-11`: `issue-audit-source.json` contains every retrieved body; `issue-audit-classification.json` records the assessment. [Card 19](cards/19-switch-over.md) records exact binaries, flags, timing limits and failed runs. Current production qualification is still in progress; earlier-head results are identified as such. Related PR #553's reverse-prefix correction is incorporated in the new retention module and has a failing-before/passing-after eviction regression; it is separate from the issue inventory.
