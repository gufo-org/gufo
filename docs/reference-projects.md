# Reference projects

Gufo builds on ideas and code from other open-source inference engines. This
page lists them and what each contributed; adapted code keeps its notices in
[THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).

- [llama.cpp](https://github.com/ggml-org/llama.cpp): compact model serving,
  GGUF, and CPU and GPU correctness paths.
- [LaurentZuijdwijk/llama.cpp](https://github.com/LaurentZuijdwijk/llama.cpp),
  [Nathanw1014/strix-halo-llamacpp](https://github.com/Nathanw1014/strix-halo-llamacpp)
  and [gaetan-puleo/llama-cpp-strix-halo](https://github.com/gaetan-puleo/llama-cpp-strix-halo):
  Strix Halo optimizations.
- [vLLM](https://github.com/vllm-project/vllm): continuous batching and paged
  request scheduling.
- [hipEngine](https://github.com/shisa-ai/hipEngine): torch-free HIP execution
  and native speculative cycles.
- [ds4](https://github.com/antirez/ds4): DeepSeek V4 Flash, MoE scheduling and
  DSpark.
- [audio.cpp](https://github.com/0xShug0/audio.cpp): speech recognition and
  synthesis models.
