| Wave64 verification attention rows > 1, October 18 | Retained for even KV head counts: the split-K fp16 verification partials run as three wave64 per pair of KV heads (four 16-lane heads per wave, twelve heads sharing both staged KV tiles) with the 16-lane score tree on DPP row exchanges.
