Usage: gufo prompt [OPTIONS] [ARGS...]

Execute one prompt request and exit.

Model:
  -m, --model <PATH>         Path to GGUF model file
      --mmproj <PATH>        Qwen BF16 vision sidecar (auto-discovered beside model)

Prompt:
      --add-vision-id        Prefix image inputs with Picture N: in the chat template
      --image <PATH>         PNG/JPEG attached before text in the first user turn; repeat for multiple images
  -p, --prompt <TEXT>        Direct input prompt text
  -f, --file <PATH>          File path to read input prompt text from
      --system <PROMPT>      Optional system role instructions prepended to the prompt
      --raw                  Disable chat template framing and pass raw tokens
      --no-display-prompt    Suppress echoing the prompt before generated response

Sampling:
  -n, --max-tokens <N>       Maximum number of new tokens to generate (default: 128)
  -t, --temperature <T>      Randomness scale; 0 selects greedy (default: model/thinking preset)
      --top-k <K>            Highest-logit token limit; 0 disables (default: model preset)
      --top-p <P>            Cumulative probability cutoff (default: model/thinking preset)
      --min-p <P>            Keep tokens with probability at least P times the best token (default: 0.0 = disabled)
      --min-keep <N>         Minimum candidates retained by enabled sampling filters (default: 0)
  -s, --seed <N>             RNG seed for reproducible generation (default: -1 = random)
      --repeat-penalty <N>   Multiplicative penalty for recently used tokens (default: 1.0 = disabled)
      --repeat-last-n <N>    Trailing token window used by repetition penalties (default: 64; 0 = disabled)
      --frequency-penalty <N> Penalty multiplied by each token's generated occurrence count (default: 0.0 = disabled)
      --presence-penalty <N> Generated-token presence penalty (default: model/thinking preset)

Reasoning:
      --think <MODE>         Reasoning mode: on, off, or auto (default: model)
      --reasoning-effort <LEVEL> Effort: auto, minimal, low, medium, high, xhigh, or max
      --preserve-thinking <MODE> Replay prior reasoning: on, off, or auto

Speculative:
      --speculative <MODE>   Draft backend: dspark (DeepSeek V4 Flash), dflash2, mtp, or off
      --dflash-model <PATH>  Path to Qwen DFlash2 GGUF file
      --draft-policy <POLICY> DFlash2 block length: fixed or adaptive (default: adaptive)
      --dspark-model <PATH>  Path to the DeepSeek V4 Flash DSpark support GGUF file
      --mtp-model <PATH>     Path to quantized Qwen MTP draft head GGUF file
  -d, --draft-tokens <N>     Maximum speculative draft tokens evaluated per step (default: 7)
      --min-draft-tokens <N> Adaptive draft floor (default: 1)

Hardware:
      --cpu                  Force CPU OpenMP execution fallback instead of GPU ROCm

General:
  -v, --verbose              Print detailed timing, latency breakdown, and tok/s metrics
  -h, --help                 Print help
