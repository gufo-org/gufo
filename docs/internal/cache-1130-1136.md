# Cache frontier and retention qualification

The cache series retains exact executed turn ends, delays preferential removal
of recent covered turns, preserves durable fallbacks under RAM pressure, and
uses prefix relations in disk eviction. The cost model remains diagnostic;
the cost-per-byte experiment is rejected.

## Cost-per-byte experiment

The replay uses the token arrays pinned at
`a32fc43bcb9ec66264f166b5162d93a9223557d5`, exported with
`tests/cache/retention_trace.py`. `cache_retention_replay` records each request's
cached/prefilled tokens and estimated interval cost as well as retention events.
It counts distinct serving turns and passes actual reuse into admission.
These historical prompt-only replays do not model generated-frontier placement,
disk I/O, numerical quality or wall time. They are not throughput measurements.

The [experimental patch](cache-1130-1136/retention-gds.patch) keeps pressure tiers,
uses the deepest retained fallback and unique payload bytes, advances a
GreedyDual watermark on pressure eviction, and updates admission/reuse stamps.
Fallback and sharing costs are recomputed during selection. Its stamp map is
outside the ledger, deliberately giving the experiment optimistic bookkeeping
cost. It is compiled separately; production has no ranking switch.

Across 330 requests, Flash-Next improves two requests; Qwen improves one and
regresses one. Six workloads have identical prefill work. The same experiment
fails the existing retention test `Branches`: it loses the checkpoint at
`{1,2,3}` while retaining the unrelated `{9,9,9}` conversation. This violates
the issue's no-regression gate, so the ranking is not adopted. The current cheap
checkpoint rule remains in production.

## Functional qualification

The same host directory retains production main/candidate binaries' evidence,
request reports, server traces, failures and follow-ups. Main is `580d053b`,
using the pinned Nix GCC 16.2 / ROCm 10.1 toolchain and lock-mode extension set.

The first Flash-Next AR candidate exposed pending generated writes displacing
prompt anchors, and the disk-spacing checker treating demotions as ordinary
spaced captures. Queue overflow now drops optional generated writes before
prompt anchors. Publications explicitly identify spacing exemptions, while the
checker still rejects too-close ordinary prompt captures.

Under high-throughput speculative decoding (DFlash2 at 80 tps), rapid completion
of multi-turn requests revealed that `Extends` and `Below` evaluated across turns
with differing prompt identity spans (`input`), preventing write-queue coalescing
of older generated frontiers across turns. Furthermore, unconstrained optional
write-through jobs could pin up to 100% of the cache RAM budget, causing
foreground capture starvation. `Extends` and `Below` now match conversation
descendants sharing either `input` or `lineage`, and `PersistenceQueue::TrySubmit`
bounds optional generated writes to half of the queue's pinned byte budget
(`max_bytes / 2`), leaving ample headroom for foreground prompt captures.

All four model profiles completed full 11-suite qualification on `gfx1151`
GPU hardware with assertions enabled, passing all functional correctness checks:

Every suite (`long-context`, `text-cancel`, `thinking-tool-cancel`,
`legacy-tool-cancel`, `disk-spacing`, `cache-persist`, and all six `-disk`
restores across restart) passed strictly.

The 2 GiB standalone interleaved thinking/tool frontier fixture
(`tests/functional/cache_frontier.py`) ran on candidate binaries for both
Flash-Next AR and Qwen27B DFlash2 under a tight 2 GiB RAM budget. In both
runs, both conversation branches (RED and BLUE) retained their executed
frontiers through slot reassignments and cold replays, restoring 1,224 tokens
directly from the retained generation state.

Matched baseline controls (`main-flash-ar`, `main-flash-mtp`, `main-qwen-ar`,
`main-qwen-dflash`) were recollected with the updated harness and masked
comparison commands. Differences against main reflect the candidate's higher
token caching and reduced prefill work upon restoring durable frontiers.
