## Orchestrator code fixes made during closure (both in the new Card 07 tools)

1. `tools/prof/card07_parity.py` resolved `--bundler` as plain `clang-offload-bundler`,
   which in the pinned dev shell rejects the zstd-compressed ROCm bundle
   (`zlib error: Z_DATA_ERROR`) and fails with a bare traceback. It now resolves the HIP
   toolchain bundler the same way `tools/ci/check-kernel-resources.py` does
   (`HIP_CLANG` → `hipconfig -l` → `PATH`), keeps `--bundler` as the override, and prints
   the failing source plus the `llvm-objcopy` PATH hint. Verified: the device gate now
   reproduces with no PATH manipulation (the row above).
2. `tools/prof/card07_host_parity.py` reported per-source counts but always exited 0, so a
   host code change could not fail it. It now compares mnemonic sequences per function and
   classifies the two move artifacts explicitly — the per-TU `__hip_cuid_*` identifier
   (including as a call target inside functions such as `__clang_call_terminate`) and
   `.L`-local string-pool offsets — and exits non-zero on any other difference, on
   `FLAG-DIFF`, or on a missing/stale mapping. First strengthened run surfaced 8 such
   call-target rows, which the CU-id mask now covers; the retained rerun above is clean.
