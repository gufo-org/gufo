## Binding design decisions (orchestrator; deviate only with written evidence)

**D1 — new `gufo_serving` static library.** Declare it in the root `CMakeLists.txt`
immediately before `add_library(gufo_http ...)`, i.e. after the warning/sanitizer
block so the sources keep the compile environment they had inside the `gufo`
executable. It owns exactly the seven sources above. PUBLIC links:
`gufo_ext_runtime gufo_core gufo_cache gufo_logging` plus whatever the interim edges
the RFC allows between steps 5 and 6 need (`gufo_cache_hip`, model/family libraries
for the text runners and `continuation_identity.cpp`'s model lines). Preserve the
`if (BUILD_TESTING)` `-UNDEBUG` treatment the previous carriers had, and keep
`ENGINE_ENABLE_HIP` OFF-build compilability. Then: the `gufo` executable drops those
seven sources and links `gufo_serving`; the three model test directories stop
re-compiling them and link `gufo_serving` instead (interim edge, documented, replaced
by `gufo_test_support` in Card 12). `gufo_http` must not link `gufo_serving`.
**Audit required:** for each of the seven sources, diff its `compile_commands.json`
entry before (per former carrier: `gufo` exe and the three test binaries) and after
(the single `gufo_serving` entry) — flags, defines (`ENGINE_ENABLE_HIP`, `-U/-D`),
includes, warnings, sanitizer state. Record the table; call out and justify every
divergence.

**D2 — neutral contracts in `gufo_ext_runtime`, headers under `src/ext/`.** Do **not**
add files under `include/gufo/ext/`: Card 10 publishes the public surface. If you are
convinced a public header is unavoidable, stop and record it as a handoff item rather
than bumping the extension API silently.
- `src/ext/continuation.hpp`: move `ContinuationInputPrefix`, `ContinuationState` and
  `ContinuationSnapshot` (and only what they need) out of
  `src/cli/serve/continuation_cache.hpp` into `gufo::ext`.
  `continuation_cache.hpp` includes it and keeps interim
  `using` aliases in `gufo::server` so every existing consumer, virtual dispatch and
  derived `TextRunnerState`/`TextRunnerSnapshot`/DeepSeek snapshot behaves exactly as
  before. Cache policy types (events, purposes, `ContinuationCache`, `Lease`,
  `ContinuationLookup`, retention) **stay in serving**.
- `src/ext/host_budget.{hpp,cpp}`: move `HostSnapshotBudgetBytes()`,
  `HostSnapshotCeilingBytes()` and their file-local host-availability helpers out of
  `text_model_runner.{hpp,cpp}`. Update all call sites; leave no duplicate declaration.
- `src/ext/device_probe.{hpp,cpp}`: the default HIP probing behind
  `HipTextModelRunner::PollDevice`/`DeviceUsable` so model runners get it from
  runtime, not serving. Must compile and link in `ENGINE_ENABLE_HIP=OFF` builds
  (guard the HIP path; do not link `hip::host` into `gufo_ext_runtime` when HIP is off).
- `src/ext/text_contracts.hpp`: the model-neutral chat/tool/tokenizer/reasoning
  pieces the runner contract embeds today (at minimum `ReasoningTags` and the tool
  format / tokenizer-id types reachable from `text_model_runner.hpp`) in `gufo::ext`,
  with interim `gufo::server` aliases. Scope strictly to what is needed for
  `src/models/**`, `src/families/**`, `src/cache/**` and `src/ext/**` to be free of
  `src/cli/**` includes. **Do not attempt the step-10 `text_model_runner.hpp` split**;
  the 46-method runner contract, `ChatRequest` ownership and the `InferenceBackend`
  model-typed `load()` overloads stay interim and must be listed as such.

**D3 — backing/resource contracts to their owners.**
- Move `ComponentCaptureBuffer` and `ComponentCacheResources` from
  `src/cli/serve/component_text_cache.hpp` into a cache-owned neutral header
  (`src/cache/component_resources.hpp`, `gufo::cache`), with interim
  `gufo::server` aliases in the serving header. No policy/queue content moves with it.
- Add the missing neutral contract: declare a backing-plan hook on
  `src/cache/adapter.hpp` (a `BackingPlan(std::size_t)` virtual or a small
  `BackingPlanner` interface — pick one, keep it minimal) implemented by the Qwen 27B
  and Flash-Next adapters, so the resource factory no longer `static_cast`s to a
  model adapter type. Model adapters keep their exact layout math;
  `qwen27b_continuation_layout_test` and
  `qwen38_flash_next_continuation_layout_test` must stay green.
- Move `CreateHipComponentCacheResources` from `inference_backend.cpp` to
  `src/core/hip/component_cache_resources.{hpp,cpp}` built into `gufo_cache_hip`.
  It receives the host ceiling and logging through **injected parameters** (callback
  or value) so `gufo_cache_hip` calls neither `server::` code nor
  `ext::HostSnapshot*` directly; serving supplies them at its two call sites.
  Preserve segment sizing, commit growth, host-reserve pressure retries, the 2 GiB
  pre-readiness reserve and every retry/log line verbatim.

**D4 — policy stays.** Queueing, scheduler priorities, API envelopes
(`openai_chat.cpp`, `http_server.cpp`), cache retention/admission, and the
model-specific identity lines in `continuation_identity.cpp` remain in
serving/core. Record them as the intentional core-owned half.

**D5 — new gates (this is the card's "focused dependency/behavior tests").**

2. A link-graph guard proving no forbidden edge from
   `gufo_ext_runtime`, `gufo_cache`, `gufo_cache_hip`, `gufo_core`, `gufo_hip_host`
   or any model/family library to `gufo_serving` or `gufo_http`. Implement it so it
   is real and provable (configure-time CMake walk of `INTERFACE_LINK_LIBRARIES`
   with a `FATAL_ERROR`, or a generated JSON checked by a `extension_link_graph_gate`
   ctest — your choice) and **prove it with a negative**: temporarily add a forbidden
   edge, capture the failure text in `/tmp/card09-logs/`, revert, and record both runs.
3. `ext_runtime_neutral_contracts_test` (in `tests/extensions/`): links
   `gufo_ext_runtime` **only** (plus what it transitively already has), and exercises
   the moved neutral continuation bases, host budget functions, backing/resource
   types and the device-probe default. If any serving or HTTP symbol were required the
   link would fail — say so in the test header comment.

**D6 — DeepSeek logging includes.** Point the three DeepSeek files at
`src/core/logging/logging.hpp` directly (no `src/cli/**` path, no new forwarding
header in `src/cli/serve/`).
